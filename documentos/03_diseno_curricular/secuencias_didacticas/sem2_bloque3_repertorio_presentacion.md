## Sesión 9 (Sem 2): Definición del show — Concepto y repertorio
### Diseño del concierto como proyecto creativo

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"¿Qué concierto queremos dar?"**: Discusión abierta. ¿Tiene un tema? ¿Un concepto? Ejemplos: "Un viaje musical" (canciones de diferentes países/géneros), "Nuestra historia" (canciones que nos representan), "Música y emociones" (alegría-tristeza-esperanza). | Compromiso: Co-diseño total. |
| **Desarrollo 1** | 30 min | **Selección de repertorio (votación + negociación):** | |
| | | *Pool de opciones:* Canciones del semestre 1, nuevos arreglos del Bloque 1, fusiones del Bloque 2, composiciones originales del grupo, canciones nuevas propuestas. | |
| | | **Criterios de selección (discutidos por el grupo):** | |
| | | - ¿Muestra lo que aprendimos? (progresión) | |
| | | - ¿Incluye a todos? (roles para cada nivel) | |
| | | - ¿Es emocionante para el público? (impacto) | |
| | | - ¿Tiene variedad? (géneros, tempos, emociones) | |
| | | - ¿Incluye algo nuestro? (composición o arreglo original) | |
| | | Seleccionar **4-5 piezas** (más que Navidad — mayor ambición). | Compromiso: Autonomía + ownership. |
| **Desarrollo 2** | 35 min | **Distribución de roles y primeras lecturas:** | |
| | | Para cada pieza, definir: director de sección vocal, director de sección instrumental, arreglista principal, roles individuales (solos, duetos, secciones). | |
| | | **NOVEDAD Sem 2:** Un alumno Nivel A puede **co-dirigir** una pieza completa (con apoyo del profesor). Otro puede **presentar** al público con micrófono. | Acción: Liderazgo estudiantil. |
| | | Primera lectura/repaso de las piezas seleccionadas. Identificar qué necesita más trabajo. | |
| | | Plan de ensayo para las próximas 5 sesiones. Los alumnos proponen la distribución del tiempo. | Compromiso: Auto-regulación grupal. |
| **Cierre** | 5 min | Compromiso grupal: "Este show es nuestro. Cada ensayo cuenta." | |
| **Tarea web** | — | Sitio web: Sección Repertorio Final actualizada con materiales de las piezas seleccionadas. Tutoriales instrumentales. | |

## Sesión 10 (Sem 2): Montaje I — Piezas nuevas y arreglos
### Aprender el material nuevo y refinar arreglos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | Calentamiento vocal + corporal enfocado en las tonalidades del repertorio nuevo. | |
| **Desarrollo** | 70 min | **Trabajo intensivo por estaciones (3 estaciones rotativas, ~22 min c/u):** | |
| | | *Estación 1 — Voces:* Montaje de líneas vocales de las piezas nuevas. Armonías a 2-3 voces (Sem 2 puede intentar 3 voces en al menos 1 pieza). Fraseo y pronunciación de letras (especialmente si hay canciones en inglés o idioma regional). | Acción: Técnica vocal avanzada. |
| | | *Estación 2 — Instrumentos:* Cifrado y partes instrumentales. Los co-directores de sección lideran (no el profesor — este observa). Nivel A puede escribir/enseñar fills y solos. Nivel B monta sus partes con cifrado. Nivel C: percusión y partes rítmicas. | Acción: Liderazgo entre pares. |
| | | *Estación 3 — Arreglos especiales:* Trabajar los momentos "wow" del show: intro impactante, transiciones entre canciones, final épico, momentos a cappella, cambios de dinámica dramáticos. Aquí trabajan los "arreglistas" de cada pieza. | Acción: Detalle creativo. |
| **Cierre** | 10 min | Juntar para una pasada rápida de la pieza que más avanzó. Celebrar progreso. | |
| **Tarea web** | — | Práctica individual con materiales del sitio web. Los co-directores de sección pueden usar el sitio para crear guías para su sección. | |

## Sesión 11 (Sem 2): Montaje II — Expresión, movimiento y concepto escénico
### Coreografía, presencia escénica y narrativa del show

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"¿Cómo se VE nuestra música?"**: Ver fragmentos de presentaciones inspiradoras (2-3 videos cortos): un coro escolar que se mueve, una banda que tiene presencia escénica, un ensamble con coreografía simple pero impactante. "¿Qué queremos que VEA el público?" | Representación: Modelos visuales. |
| **Desarrollo 1** | 35 min | **Diseño del show completo:** | |
| | | *Orden de canciones* (dramaturgia — ya lo saben del Sem 1): Apertura energética → Pieza emotiva → Composición original → Pieza divertida/fusión → Cierre épico. | |
| | | *Transiciones:* ¿Encadenamos canciones? ¿Hay narración entre piezas? ¿Un alumno presenta cada pieza explicando por qué la eligieron? | Compromiso: Storytelling personal. |
| | | *Movimiento escénico por pieza:* ¿Quiénes están al frente? ¿Hay formación diferente para cada canción? ¿Movimiento coreográfico simple en alguna pieza? ¿Cambios de posición entre canciones? | Acción: Corporal + espacial. |
| | | *Vestuario y elementos visuales:* ¿Color unificado? ¿Temática visual? ¿Luces? (lo que sea posible en el espacio). | |
| **Desarrollo 2** | 35 min | **Ensayo con movimiento:** Pasada del programa completo con posiciones, transiciones y movimiento. NO necesita ser perfecto musicalmente todavía — el foco es el FLUJO del show. | Acción: Integración cuerpo + música. |
| **Cierre** | 10 min | Asignar tareas específicas: presentador(es), utilería, playlist de entrada del público, programa de mano (¿un alumno lo diseña?), grabación (¿quién filma?). | Compromiso: Ownership del evento completo. |
| **Tarea web** | — | Repasar todas las piezas en casa con los materiales del sitio. | |

## Sesión 12 (Sem 2): Ensayo general I — Primera corrida completa
### Flujo completo con auto-evaluación

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | Calentamiento vocal + corporal intenso. Enfoque mental: "Hoy ensayamos como si fuera el día del concierto." | |
| **Desarrollo** | 65 min | **Corrida completa** del programa (4-5 piezas + transiciones + presentaciones). Sin parar, como si fuera en vivo. | |
| | | **Grabación** (video) para auto-evaluación. | |
| | | **Revisión (20 min):** Ver fragmentos clave. Lista colaborativa: ✅ Lo que funciona / ⚠️ Lo que necesita trabajo / 🌟 Los momentos brillantes. | Compromiso: Auto-crítica constructiva. |
| | | **Trabajo focalizado (15 min):** Solo las partes marcadas con ⚠️. Repetir hasta mejorar. | |
| **Cierre** | 5 min | "¿Estamos más listos que en el ensayo de Navidad? ¿Qué es diferente esta vez?" (Respuesta esperada: más seguros, más autónomos, más ambiciosos). | |
| **Tarea web** | — | Repaso final individual. Memorizar letras y transiciones. | |

## Sesión 13 (Sem 2): Ensayo general II — Pulido y confianza final
### Detalle, manejo de nervios y ritual de cierre

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"Respiración y visualización"**: Técnica de respiración anti-nervios (4-7-8). Visualización guiada del concierto exitoso. "Cierren los ojos. Imaginen que están en el escenario. El público aplaude. La música suena increíble. Sienten orgullo." | SEL: Autogestión emocional. |
| **Desarrollo** | 65 min | **Corrida final #1** — completa, sin parar. | |
| | | **Ajustes quirúrgicos** (20 min) — solo lo imprescindible. | |
| | | **Corrida final #2** — la definitiva. Grabación. | |
| | | Si hay tiempo y energía: **corrida #3** solo de la pieza que más les gusta (disfrutar, no perfeccionar). | |
| **Cierre** | 15 min | **Ritual de cierre del año:** | Compromiso: Comunidad, emoción. |
| | | *Círculo de gratitud:* De pie en círculo. Cada alumno dice una frase: "Gracias a [nombre] por [algo musical o personal que hizo este año]." | SEL: Conciencia social, relaciones. |
| | | Profesor cierra: "Lo que vivimos juntos este año a través de la música no se mide con una calificación. Se mide con lo que sentimos ahora mismo." | |
| | | "Mañana/la próxima semana, lo compartimos con el mundo." | |
| **Tarea web** | — | Repaso final. Preparar vestuario/accesorios. Llegar puntuales y con energía. | |

## Sesión 14 (Sem 2): 🎆 PRESENTACIÓN FINAL DE JUNIO
### Producto integrador del Semestre 2 y cierre de año

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Crear e interpretar** una presentación musical que integre repertorio diverso, composiciones originales, arreglos propios, técnica vocal e instrumental, expresión artística y presencia escénica. **Evaluar** el crecimiento del año completo. |
| **Competencias MEFI** | CDBDHI5 + CDBDHI10 + CDBDHI17 (máxima integración) |

#### Estructura

| Momento | Tiempo | Actividad |
|---------|--------|-----------|
| **Pre-show** | 20 min | Calentamiento vocal + corporal. Círculo de energía. Verificación de instrumentos, posiciones, programa de mano. Respiración grupal: "Inhalar juntos, exhalar juntos, empezar juntos." |
| **Presentación** | 50-60 min | Ejecución del programa completo (4-5 piezas + transiciones + presentaciones verbales de alumnos). Ante público. Incluye: al menos 1 pieza original o arreglo propio del grupo. |
| **Post-show** | 20 min | **Celebración** — fotos, abrazos, reconocimiento público del profesor. |
| | | **Evaluación reflexiva final** (puede ser en la siguiente clase si no hay tiempo, o en sitio web): |
| | | 1) ¿Quién era yo musicalmente en agosto? ¿Quién soy ahora en junio? |
| | | 2) ¿Cuál fue mi momento favorito del año? |
| | | 3) ¿Qué aprendí de mí a través de la música? |
| | | 4) ¿Qué aprendí de los demás? |
| | | 5) Si pudiera decirle algo al yo de agosto, ¿qué le diría? |
| | | 6) ¿Quiero seguir haciendo música? ¿Cómo? |

#### Evaluación sumativa
- **Rúbrica de presentación** (grupal + individual) — peso según assessment blueprint
- **Autoevaluación reflexiva final** — parte del portafolio
- **Coevaluación** — reconocimiento entre pares
- **Portafolio musical completo** — evidencias del año (bitácora, grabaciones, composiciones, reflexiones)

## Comparativa Sem 1 vs. Sem 2

| Aspecto | Presentación Navidad (Sem 1) | Presentación Final (Sem 2) |
|---------|------------------------------|---------------------------|
| Piezas | 3-4 | 4-5 |
| Material original | No | Sí (composición/arreglo propio) |
| Dirección | Profesor dirige todo | Co-dirección con alumnos |
| Arreglos | Profesor diseña | Alumnos co-diseñan |
| Presentación verbal | Profesor o 1 alumno | Alumnos presentan sus piezas |
| Complejidad vocal | 2 voces | 2-3 voces |
| Movimiento escénico | Básico (posiciones) | Coreografía simple + cambios |
| Autonomía general | Media (profesor guía) | Alta (alumnos lideran) |
