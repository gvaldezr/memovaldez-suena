# 🎤 Semestre 1 — Bloque 2: Técnica Vocal y Ensamble
## Sesiones 5–8 | "Desarrollo Físico y Artístico"

> **Eje:** Desarrollar la voz como instrumento principal del taller y consolidar el ensamble como forma de expresión colectiva.
> **Hilo conductor:** "Tu voz es tu instrumento más personal — aprendamos a usarla juntos."

---

## Visión general del bloque

| Aspecto | Detalle |
|---------|---------|
| **Sesiones** | 4 (360 min total) |
| **Competencias MEFI** | CDBDHI10 (corporeidad artística), CDBDHI17 (emociones por arte) |
| **Genéricas** | CG8 (colaboración), CG10 (gestión emocional), CG12 (relaciones interpersonales) |

## Sesión 5: Descubriendo mi voz
### Técnica vocal básica y clasificación vocal

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Aplicar** técnicas básicas de respiración y emisión vocal, y **clasificar** (Analizar) su rango vocal aproximado (soprano/alto para voces agudas, tenor/bajo para voces graves). |
| **Competencias MEFI** | CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Autoconciencia (conocer mi instrumento corporal), Autogestión (controlar la respiración) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"El cuerpo que respira"**: Ejercicios de respiración diafragmática disfrazados de juego: inflar globo imaginario (expandir costillas), soplar velita a distancia (control del aire), la serpiente (sss sostenido — contar quién dura más). De pie, en círculo. | **Acción:** Corporal, todos participan. **Compromiso:** Reto lúdico (¿quién dura más?). |
| **Desarrollo 1** | 25 min | **Técnica vocal en 4 pasos** (sin jerga técnica): | |
| | | *1. Postura:* "Imagina que un hilo te jala desde la coronilla." De pie, hombros relajados, pies separados. | **Representación:** Imagen mental + modelado del profesor. |
| | | *2. Respiración:* Inhalar en 4 tiempos, sostener 4, exhalar en 8 (con sss). Repetir con vocales (aaa, ooo). | **Acción:** Progresivo, medible. |
| | | *3. Resonancia:* Humming (mmm) con mano en pecho (sentir vibración) → mano en nariz → mano en frente. "El sonido viaja por tu cuerpo." | **Representación:** Kinestésico (sentir las vibraciones). |
| | | *4. Vocalización:* Escala de 5 notas (Do-Re-Mi-Fa-Sol-Fa-Mi-Re-Do) sobre "ma-me-mi-mo-mu". Subir medio tono cada repetición. | **Acción:** Gradual, sin presión. |
| | | **Clasificación vocal lúdica:** Profesor toca notas cada vez más agudas y luego más graves. "Levanta la mano cuando ya no puedas/quieras cantar la nota." Asignar COLORES, no etiquetas intimidantes: Voz Azul (aguda) / Voz Verde (media) / Voz Roja (grave). | **Compromiso:** Sin etiquetas técnicas, con colores. **Representación:** Auditivo + visual. |
| **Desarrollo 2** | 30 min | **Primera pieza a 2 voces: "Hallelujah" (Leonard Cohen) — versión simplificada** o similar elegida por profesor. | **Compromiso:** Canción emotiva, universalmente conocida. |
| | | *Paso 1:* Escuchar versión de referencia (audio). Identificar verso/coro. | **Representación:** Auditivo. |
| | | *Paso 2:* Aprender melodía principal (todos) por imitación frase a frase. | **Acción:** Imitación oral. |
| | | *Paso 3:* Dividir: Voces Azules/Verdes = melodía. Voces Rojas = línea de bajo/segunda voz (3as paralelas o nota pedal en "oooh"). | **Diferenciación:** Por rango vocal natural, no por "nivel". |
| | | *Paso 4:* Juntar las 2 líneas vocales. Piano sostiene la armonía. | |
| | | Nivel A instrumental: acompañamiento con guitarra/piano (cifrado). Nivel B: bajo o guitarra con acordes simples. Nivel C: percusión suave (shaker, pandereta). | **Acción:** Cada nivel con su rol. |
| **Cierre** | 10 min | **Bitácora:** "¿Cómo suena mi voz cuando la uso con intención? ¿Me sorprendí?" Compartir voluntario. Tarea web anunciada. | **Compromiso:** Metacognición vocal. |
| **Tarea web** | — | Sitio web → "Módulo 4: Mi Voz" — Video de técnica de respiración, ejercicios de vocalización con audio guía, infografía de rangos vocales con colores. | |

#### Materiales y recursos
- Piano del aula (referencia de afinación y acompañamiento)
- Letras impresas/proyectadas de la canción (con cifrado y melodía simplificada)
- Sitio web: Módulo 4 — Mi Voz

## Sesión 6: Armonía — el arte de sonar juntos
### Intervalos básicos, acordes y armonización vocal

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Distinguir** (Analizar) entre melodía y armonía, e **interpretar** (Aplicar) una segunda voz o acompañamiento armónico. |
| **Competencias MEFI** | CDBDHI5, CDBDHI17 |
| **SEL/CASEL** | Habilidades de relación (escuchar al otro sin perder tu parte) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"El juego de los intervalos"**: Profesor toca 2 notas en piano. Grupo clasifica: "¿Suenan BIEN juntas (consonante) o RARO (disonante)?" Pulgar arriba/abajo. Luego: "¿Suenan CERCA (2a, 3a) o LEJOS (5a, 8a)?" Manos juntas/separadas. Sin nombres técnicos al inicio — pura percepción. | **Representación:** Auditivo + kinestésico (gestos). **Compromiso:** Juego de percepción, bajo riesgo. |
| **Desarrollo 1** | 25 min | **Construir un acorde con el cuerpo:** | |
| | | Dividir grupo en 3. Grupo 1 canta y sostiene DO. Grupo 2 canta y sostiene MI. Grupo 3 canta y sostiene SOL. → "¡Eso es un acorde de Do Mayor!" | **Representación:** Corporal — cada persona ES una nota del acorde. |
| | | Mover a RE-FA-LA (Re menor). "¿Suena diferente? ¿Qué emoción les provoca?" Mayor=alegre, menor=melancólico (simplificación didáctica). | **Compromiso:** Conexión emocional con los sonidos. |
| | | **Para instrumentistas (A/B):** Tocar los mismos acordes en guitarra/piano. Ver la relación entre lo que cantan y lo que tocan. | **Representación:** Transferencia voz → instrumento. |
| | | **Para Nivel C:** Mantener tu nota sin moverte — ejercicio de concentración y escucha. Si es muy difícil, cantar con el grupo más grande (DO). | |
| **Desarrollo 2** | 30 min | **Práctica de armonización en canción:** Continuar la pieza de la Sesión 5 (o nueva). Trabajar específicamente: | |
| | | *Coro a 2 voces:* Melodía (voces agudas) + 3a inferior o contracanto (voces graves). Enseñar la segunda voz por imitación, frase por frase. | **Representación:** Imitación primero, luego partitura/cifrado para quien la quiera. |
| | | *Ensamble instrumental:* Definir roles más claros: guitarra rítmica (acordes), guitarra/piano melódico (intro/fills), bajo (fundamentales), batería (patrón básico), percusión menor (color rítmico). | **Acción:** Roles definidos, rotables. |
| | | **Ensayo por secciones** (10 min) → **Ensayo tutti** (10 min) → **Pasada completa** (10 min). | |
| **Cierre** | 10 min | **Escucha activa:** Grabar (celular) la última pasada y reproducir al grupo. "¿Qué escuchamos? ¿Qué funciona? ¿Qué podemos mejorar?" Primer ejercicio de auto-crítica constructiva. | **Compromiso:** Escucharse = meta-cognición musical. |
| **Tarea web** | — | Sitio web → "Módulo 5: Armonía" — Explicación visual de intervalos con audio. Acorde mayor vs. menor con ejemplos de canciones conocidas. | |

#### Materiales y recursos
- Piano para demostración de intervalos y acordes
- Grabadora/celular para grabar la pasada final
- Bocina para reproducir la grabación
- Cifrado impreso con segunda voz
- Sitio web: Módulo 5 — Armonía

## Sesión 7: Dinámicas y expresión — de tocar notas a hacer música
### Matices, fraseo y expresividad musical

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Interpretar** (Aplicar) una pieza musical con dinámicas (piano/forte) y fraseo expresivo, y **evaluar** (Evaluar) el impacto emocional de los matices en la música. |
| **Competencias MEFI** | CDBDHI17 (expresión emocional), CDBDHI10 (corporeidad) |
| **SEL/CASEL** | Autoconciencia emocional, Autogestión (modular la intensidad) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"El semáforo de volumen"**: Profesor levanta tarjetas de colores: Verde = pianísimo (muy suave), Amarillo = mezzo (medio), Rojo = forte (fuerte). Grupo canta una nota sostenida y cambia volumen según la tarjeta. Luego: crescendo (verde → rojo gradual) y diminuendo (rojo → verde). | **Representación:** Visual (colores) + auditivo. **Acción:** Corporal (control de aire). |
| **Desarrollo 1** | 20 min | **La misma canción, 3 emociones:** Tomar una frase de la pieza del repertorio. Cantarla: 1) Como si fuera un secreto (pp, legato) 2) Como si estuvieras enojado (ff, staccato) 3) Como si te despidieras de alguien (mp, con rubato). | **Compromiso:** Conexión emocional directa. **Representación:** La música como vehículo de emociones. |
| | | Discusión: "¿Qué cambió? ¿Las notas eran las mismas?" → Concepto: la música no es solo notas — es CÓMO las tocas/cantas. | |
| | | **Para instrumentistas:** Mismo ejercicio en su instrumento. ¿Cómo suena un acorde de guitarra rasguado suave vs. fuerte? ¿Piano con pedal vs. staccato? | **Acción:** Transferencia a cada instrumento. |
| **Desarrollo 2** | 35 min | **Ensayo expresivo de la pieza del repertorio:** | |
| | | Trabajar la pieza con mapa de dinámicas dibujado en pizarrón: línea de onda que sube (cresc.) y baja (dim.) sobre la letra. El profesor dirige con gestos de volumen (manos arriba/abajo). | **Representación:** Visual (mapa dinámico) + gestual (dirección). |
| | | *Verso:* mp (medio-suave), intimista | |
| | | *Pre-coro:* crescendo gradual | |
| | | *Coro:* forte, pleno, todos juntos | |
| | | *Puente:* pianísimo — solo voces a cappella (momento dramático) | |
| | | *Coro final:* fortísimo con todo el ensamble | |
| | | **Nivel A:** Puede dirigir una sección. Agrega ornamentación (fills, improvisación en momentos específicos). | |
| | | **Nivel B:** Aplica dinámicas en su instrumento. Experimenta con diferentes ataques. | |
| | | **Nivel C:** Sigue las tarjetas de color del profesor. Percusión suave/fuerte según la sección. | |
| | | Grabar 2 versiones: una "plana" (todo al mismo volumen) y una con dinámicas. Comparar. | **Compromiso:** Evidencia tangible del progreso expresivo. |
| **Cierre** | 10 min | **Bitácora reflexiva:** "¿Qué emoción quiero transmitir cuando hagamos nuestra presentación de Navidad?" Primer diálogo sobre el concierto como meta emocional, no solo musical. | **Compromiso:** Proyección al producto integrador. |
| **Tarea web** | — | Sitio web → "Módulo 6: Expresión Musical" — Video comparativo de interpretaciones con/sin dinámicas. Glosario ilustrado: piano, forte, crescendo, diminuendo, legato, staccato. | |

## Sesión 8: Ensayo integrador del Bloque 2
### Consolidación técnica-expresiva y preparación para repertorio navideño

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Ejecutar** (Aplicar) una pieza completa con técnica vocal, armonía a 2 voces, ensamble instrumental y dinámicas expresivas. **Evaluar** el resultado grupal y proponer mejoras. |
| **Competencias MEFI** | CDBDHI5, CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Todas las competencias: autoconciencia, autogestión, conciencia social, relaciones, decisiones |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **Calentamiento integral:** 3 min respiración → 3 min vocalización (escala con dinámicas) → 4 min body percussion groove. "Estamos calentando TODO: cuerpo, voz y oído." | **Acción:** Rutina que ya dominan. |
| **Desarrollo 1** | 30 min | **Ensayo de la pieza del repertorio (la más trabajada hasta ahora):** Pasada completa → Notas del profesor → Trabajo por secciones (voces, instrumentos, percusión) → Pasada completa mejorada. | |
| | | **Foco:** Aplicar TODO lo aprendido en el bloque: respiración, emisión, armonía a 2 voces, dinámicas, fraseo. | |
| | | **Ejercicio de escucha cruzada:** Voces cantan mientras instrumentistas SOLO escuchan. Luego al revés. "¿Qué descubres cuando solo escuchas?" | **Compromiso:** Empatía musical. |
| **Desarrollo 2** | 30 min | **Votación de repertorio navideño:** Profesor presenta 6-8 opciones de canciones para la presentación de Diciembre (mezcla de villancicos, canciones navideñas pop, soundtrack navideño). Escuchar fragmentos. Votar. Seleccionar 3-4 piezas. | **Compromiso:** Autonomía — los alumnos eligen su repertorio. |
| | | **Opciones sugeridas (adaptables):** | |
| | | - "All I Want for Christmas Is You" (Mariah Carey) — pop, energético | |
| | | - "Noche de Paz" — villancico clásico, versión a cappella | |
| | | - "El Burrito Sabanero" — música latina navideña, percusión | |
| | | - "Let It Snow" o "Have Yourself a Merry Little Christmas" — jazz suave | |
| | | - "Carol of the Bells" — reto coral impresionante | |
| | | - Medley de villancicos yucatecos/mexicanos | |
| | | Primera lectura de la pieza más votada: melodía por imitación, cifrado en pizarrón. | |
| **Cierre** | 10 min | **Evaluación intermedia de bloque:** Autoevaluación escrita breve: 1) ¿Qué habilidad musical nueva adquirí? 2) ¿Qué me cuesta más? 3) ¿Qué rol quiero tener en la presentación? Compartir respuestas con el profesor para ajustar roles y diferenciación. | **Compromiso:** Voz del alumno en su proceso. |
| **Tarea web** | — | Sitio web → Sección "Repertorio Navideño": Audios de referencia de las canciones seleccionadas, cifrado, letras, tutoriales de las partes instrumentales. | |
