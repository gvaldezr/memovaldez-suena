# 🎨 Semestre 2 — Bloque 2: Creatividad y Composición
## Sesiones 5–8 | "Creatividad en Movimiento"

> **Eje:** Pasar de intérpretes a creadores — componer, improvisar y experimentar con la música como forma de expresión personal.
> **Hilo conductor:** "La música que falta en el mundo es la que TÚ puedes crear."

## Sesión 5 (Sem 2): Improvisación — Perder el miedo a crear
### Improvisación rítmica, melódica y vocal

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Crear** secuencias musicales espontáneas dentro de un marco rítmico/armónico dado, y **evaluar** la propia capacidad de expresión improvisada. |
| **Competencias MEFI** | CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Autogestión (tolerar la incertidumbre), Autoconciencia (descubrir creatividad propia) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"El círculo de improvisación rítmica"**: En círculo, cada alumno agrega 1 sonido corporal (palma, stomp, chasquido, golpe en muslo, sonido vocal) al groove grupal. Se acumula. Si te equivocas, el error se convierte en parte del groove. **Regla de oro: NO HAY ERRORES EN LA IMPROVISACIÓN — hay descubrimientos.** | Compromiso: Espacio seguro. Acción: Participación universal. |
| **Desarrollo 1** | 25 min | **Improvisación melódica guiada — "El pentatónico mágico"**: | |
| | | Enseñar la escala pentatónica (Do-Re-Mi-Sol-La) — "Estas 5 notas siempre suenan bien juntas, en cualquier orden." | Representación: Escala simplificada = seguridad. |
| | | **Nivel C:** Cantar notas aleatorias de la pentatónica sobre un groove de palmas. O tocar las 5 notas en xilófono/piano. | Acción: Bajísimo riesgo, máximo resultado. |
| | | **Nivel B:** Improvisar riffs en guitarra/bajo usando la pentatónica. Aportar licks de canciones que conocen. | Acción: Conectar conocimiento previo. |
| | | **Nivel A:** Improvisar melodías más elaboradas, con ritmos variados, sobre progresión I-IV-V tocada por el profesor. | Acción: Reto apropiado. |
| | | **Formato "Jam circle"**: Profesor toca progresión en loop (piano o guitarra). Cada alumno improvisa 4 compases y pasa al siguiente. Grupo aplaude cada turno — celebrar la valentía, no la perfección. | Compromiso: Apoyo del grupo, brevedad (4 compases = manejable). |
| **Desarrollo 2** | 30 min | **Improvisación vocal — "Beatbox + Scat"**: | |
| | | *Beatbox básico (10 min):* Enseñar 3 sonidos básicos: bombo (b), hi-hat (ts), caja (pf). Armar beat simple: "b-ts-pf-ts". Freestyle sobre la base. Quien quiera, rapea o hace scat encima. | Acción: Urbano, relevante generacionalmente. |
| | | *Scat jazz ligero (10 min):* Sobre progresión de blues (I-I-I-I-IV-IV-I-I-V-IV-I-V), cantar con sílabas inventadas (du-ba-di-da). No hay letra "correcta" — puro sonido expresivo. | Compromiso: Liberación de la necesidad de "hacerlo bien". |
| | | *Improvisación grupal libre (10 min):* Sin reglas. "Hagan música juntos. Escúchense. Respondan." Profesor inicia con un patrón y gradualmente se retira. El grupo se auto-organiza. Momento de flow colectivo. | Compromiso: Experiencia cumbre de autonomía musical. |
| **Cierre** | 10 min | **Reflexión profunda:** "¿Qué descubriste que podías hacer y no sabías? ¿Cómo se siente crear algo que no existía antes?" Bitácora: escribir o dibujar la experiencia. | SEL: Autoconciencia creativa. |
| **Tarea web** | — | Sitio web → "Módulo 11: Improvisación" — Video sobre escala pentatónica con backing tracks para practicar en casa. Ejercicios de improvisación guiada con audio. "Impro-reto semanal": improvisar 1 minuto diario y reflexionar. | |

## Sesión 6 (Sem 2): Composición I — De la idea a la canción
### Proceso creativo, estructura de canción, escritura de letras y melodías

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Crear** una canción original (letra + melodía + armonía) siguiendo un proceso estructurado. |
| **Competencias MEFI** | CDBDHI17 (expresión emocional), CDBDHI10 |
| **SEL/CASEL** | Autoconciencia (expresar emociones propias), Toma de decisiones |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"El origen de tus canciones favoritas"**: Escuchar testimonios breves (video) de compositores famosos sobre cómo escribieron sus canciones (ej. Ed Sheeran sobre "Thinking Out Loud", Manzanero sobre "Somos Novios", Bad Bunny sobre su proceso). Mensaje: componer es para todos. | Compromiso: Modelos a seguir relevantes. |
| **Desarrollo 1** | 25 min | **Framework de composición — "Receta básica de canción"**: | Representación: Framework visual paso a paso. |
| | | En pizarrón o proyección: | |
| | | **Paso 1 — ¿Qué quieres decir?** Tema/emoción (amor, amistad, pérdida, rebeldía, esperanza, humor). Escribir 3 frases sobre ese tema. | |
| | | **Paso 2 — ¿Con qué acordes?** Elegir una progresión (I-V-vi-IV, I-IV-V-I, etc.). Tocar en loop. | |
| | | **Paso 3 — ¿Cómo suena la melodía?** Cantar/tararear sobre los acordes. La melodía nace de la repetición y la intuición. | |
| | | **Paso 4 — ¿Cuál es la forma?** Verso-Coro-Verso-Coro (la más simple). | |
| | | **Demostración en vivo:** Profesor compone una mini-canción de 30 segundos en vivo con aporte del grupo. "¿Ven? No es magia." | Compromiso: Desmitificar la composición. |
| **Desarrollo 2** | 40 min | **Taller de composición en equipos (4-5 alumnos):** | Acción: Creación colectiva. |
| | | Cada equipo crea una canción/pieza original de al menos 1 verso + 1 coro (1-2 min). | |
| | | **Opciones creativas (DUA):** | |
| | | a) Canción con letra y melodía (para quienes quieran escribir) | |
| | | b) Pieza instrumental con estructura clara (para quienes prefieran no cantar) | |
| | | c) Pieza rítmica/percusiva con groove, breaks y dinámica (para percusionistas) | |
| | | d) Mashup/arreglo creativo de 2 canciones existentes combinadas | |
| | | **Roles dentro del equipo:** Letrista, melodista, armonista, arreglista rítmico. Todos aportan algo. | Acción: Roles diferenciados, todos contribuyen. |
| | | Nivel A: Pueden escribir la partitura/cifrado de la composición. | |
| | | Nivel B: Aportan melodías e ideas armónicas de oído. | |
| | | Nivel C: Aportan letra, ritmo, ideas de forma, o percusión. | |
| **Cierre** | 5 min | "Para la próxima clase, traigan su canción más avanzada — la vamos a pulir y grabar." Emoción y expectativa. | |
| **Tarea web** | — | Sitio web → "Módulo 12: Composición" — Guía paso a paso de composición. Plantilla de estructura de canción descargable. Backing tracks en diferentes progresiones para componer encima. Ejemplos de composiciones de estudiantes anteriores (si hay). | |

## Sesión 7 (Sem 2): Composición II — Pulir, ensayar y grabar
### Refinamiento de composiciones y registro

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Evaluar** y **mejorar** la composición grupal, y **crear** un registro (grabación) de la pieza. |
| **Competencias MEFI** | CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Habilidades de relación (dar y recibir feedback), Autogestión (mejorar con crítica) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 5 min | Breve energizer musical (body percussion groove colectivo — ya es ritual). | |
| **Desarrollo 1** | 35 min | **"Clínica de composición"**: Cada equipo toca su composición al grupo (3 min). El grupo da feedback con el método "2 estrellas + 1 deseo" (2 cosas que les gustaron + 1 sugerencia de mejora). Profesor complementa con sugerencias técnicas. | Compromiso: Feedback constructivo entre pares. |
| | | Los equipos regresan a trabajar incorporando el feedback (15 min). | Acción: Iterar = proceso creativo real. |
| **Desarrollo 2** | 35 min | **Sesión de grabación:** Cada equipo graba su canción (celular con buena posición = suficiente, o micrófonos si hay). | |
| | | Proceso por equipo (~8 min): | |
| | | 1) Soundcheck rápido (¿se escucha todo?) | |
| | | 2) Toma 1 (completa, sin parar) | |
| | | 3) Escuchar juntos → ¿otra toma? | |
| | | 4) Toma 2 (definitiva) | |
| | | **Mientras un equipo graba, los demás ensayan o trabajan en sus arreglos para la presentación final.** | Acción: Tiempo bien distribuido. |
| **Cierre** | 5 min | "Sus composiciones van al sitio web (si aceptan) como inspiración para futuros estudiantes. ¡Crearon algo que no existía en el mundo!" | Compromiso: Legado, trascendencia. |
| **Tarea web** | — | Sitio web → Sección "Nuestras Creaciones": Subir las grabaciones (con permiso). Muro de composiciones del grupo. | |

## Sesión 8 (Sem 2): Experimentación y fusión — Géneros cruzados
### Exploración de géneros, fusión y búsqueda de identidad musical del grupo

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Crear** un arreglo que fusione 2 géneros musicales diferentes, y **evaluar** el resultado como expresión de identidad grupal. |
| **Competencias MEFI** | CDBDHI5 (identidad cultural), CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Conciencia social (apreciar diferentes culturas musicales), Toma de decisiones |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Playlist de la generación"**: Cada alumno escribió en un papel su canción favorita actual. El profesor las puso en una playlist y reproduce fragmentos (15 seg c/u). Identificar: ¿qué géneros escuchamos? ¿Rock, pop, reggaetón, K-pop, trap, corridos, trova, regional mexicano, soundtrack, electrónica? Mapear los géneros del grupo en el pizarrón. | Compromiso: Su música, su identidad. |
| **Desarrollo 1** | 20 min | **"Frankenstein musical"**: ¿Qué pasa si combinamos reggaetón con trova yucateca? ¿K-pop con marimba? ¿Trap con villancico? Profesor demuestra una fusión absurda para romper el hielo (ej. "Cielito Lindo" en ritmo de reggaetón — funciona sorprendentemente bien). | Compromiso: Humor + creatividad sin límites. |
| | | Discusión: la fusión NO es una broma — es cómo nace la música nueva (jazz = blues + gospel, reggaetón = dancehall + hip hop, rock en tu idioma = punk + español). | Representación: Contexto cultural. |
| **Desarrollo 2** | 40 min | **Taller de fusión en equipos:** | Acción: Máxima autonomía creativa. |
| | | Cada equipo elige 2 géneros y crea un arreglo de fusión de una canción conocida (o crea algo nuevo). | |
| | | **Opciones sugeridas:** | |
| | | - Cumbia + Disney (ej. "Bajo el Mar" en cumbia) | |
| | | - Rock + trova yucateca (ej. "Peregrina" con guitarra eléctrica y batería) | |
| | | - Pop + son jarocho (ej. "La Bamba" meets "Shape of You") | |
| | | - Soundtrack + percusión latina (ej. tema de Harry Potter con congas y timbales) | |
| | | 30 min de trabajo → 10 min de presentaciones. | |
| | | **Votación:** ¿Cuál fusión incluimos en el repertorio de la presentación final de junio? | Compromiso: Autonomía sobre el repertorio final. |
| **Cierre** | 5 min | **Transición al Bloque 3:** "Ahora que sabemos interpretar, arreglar, componer y fusionar, tenemos todo para hacer la mejor presentación del año. Ustedes deciden el repertorio." | |
| **Tarea web** | — | Sitio web → "Módulo 13: Géneros y Fusión" — Mapa interactivo de géneros musicales (de dónde vienen, cómo se conectan). Audio-ejemplos de fusiones exitosas. Encuesta: "¿Qué quieres tocar en la presentación final?" | |
