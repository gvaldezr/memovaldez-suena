# 🎼 Semestre 2 — Bloque 1: Profundización Musical
## Sesiones 1–4 | "Creatividad en Movimiento"

> **Eje:** Evaluar el crecimiento del semestre anterior y profundizar en armonía, arreglos y lectura musical.
> **Hilo conductor:** "Ya sabemos hacer música — ahora vamos a entenderla y transformarla."

---

| Aspecto | Detalle |
|---------|---------|

## Sesión 1 (Sem 2): ¿Cuánto crecimos? — Evaluación y re-diagnóstico
### Evaluación de progreso + nuevas metas

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Evaluar** el propio crecimiento musical comparando con el diagnóstico inicial, y **establecer** (Crear) metas personales para el segundo semestre. |
| **Competencias MEFI** | CDBDHI10 (autocuidado a través del arte), CDBDHI17 |
| **SEL/CASEL** | Autoconciencia (meta-reflexión), Autogestión (fijar metas) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Círculo de sonido 2.0"** (callback a Sesión 1 del Sem 1): Mismo ejercicio — cada alumno dice su nombre y hace un sonido/ritmo que lo represente AHORA. Comparar con la memoria del primer día. "¿Notan la diferencia?" | Compromiso: Reconocer el crecimiento. |
| **Desarrollo 1** | 25 min | **Re-diagnóstico musical** (mismas 4 estaciones del Sem 1 pero con nivel elevado): | Representación: Multi-modal. |
| | | *Estación 1 — Ritmo:* Patrones más complejos (sincopas, compases compuestos). Body percussion a 2 capas simultáneas. | |
| | | *Estación 2 — Voz:* Cantar una melodía a 2 voces en dúo con otro alumno. Evaluar independencia vocal. | |
| | | *Estación 3 — Instrumento:* Tocar una progresión de 4 acordes y una melodía sobre ella. Los que no tocaban instrumento en Sem 1, ¿lo hacen ahora? | |
| | | *Estación 4 — Lectura:* Leer a primera vista un fragmento melódico simple (pentagrama, cifrado o tab según nivel). | |
| | | **Profesor:** Comparar checklist con diagnóstico de Sem 1. Documentar progresión individual. | Acción: Evidencia tangible de avance. |
| **Desarrollo 2** | 30 min | **"Mapa de mi viaje musical"**: Cada alumno crea un mapa visual (en papel o digital) de su progresión: | Representación: Visual + narrativo. |
| | | - ¿Dónde empecé? (Sem 1, Sesión 1) | |
| | | - ¿Qué aprendí? (habilidades, canciones, momentos clave) | |
| | | - ¿Dónde estoy ahora? | |
| | | - ¿Adónde quiero llegar al final del año? (metas Sem 2) | |
| | | Compartir en tríos (5 min) → Voluntarios al grupo (5 min). | Compromiso: Narrativa personal. |
| | | **Establecer metas personales** (3 metas concretas y medibles): Ej. "Quiero aprender a leer partitura básica", "Quiero cantar un solo", "Quiero aprender un instrumento nuevo". | |
| **Cierre** | 10 min | **Presentación del Semestre 2:** Explicar el enfoque de "Creatividad en movimiento" — este semestre crearemos nuestros propios arreglos, composiciones, y la presentación final será más ambiciosa. Más autonomía, más HEI (trabajo en casa con el sitio web). | |
| **Tarea web** | — | Sitio web → "Módulo 7: Evaluación de progreso" — Autoevaluación comparativa: ¿qué sabía en agosto vs. qué sé ahora? Encuesta interactiva de establecimiento de metas. | |

## Sesión 2 (Sem 2): Armonía avanzada — Progresiones que cuentan historias
### Progresiones armónicas, funciones tonales y emociones

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Analizar** las funciones armónicas básicas (tónica, subdominante, dominante) y **relacionar** (Analizar) las progresiones con emociones y géneros musicales. |
| **Competencias MEFI** | CDBDHI17, CDBDHI5 |
| **SEL/CASEL** | Conciencia social (cómo la música afecta a otros) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Las 4 progresiones que dominan la música pop"**: Profesor toca en piano/guitarra la progresión I-V-vi-IV (Do-Sol-Lam-Fa) y pregunta: "¿Qué canciones conocen con estos acordes?" (Respuesta: MUCHAS — Let It Be, No Woman No Cry, Someone Like You, Despacito intro, etc.) → Impacto: 4 acordes = cientos de canciones. | Compromiso: Conexión con su música. Representación: Auditivo + cultural. |
| **Desarrollo 1** | 25 min | **Funciones tonales — sin jargon intimidante:** | |
| | | *La casa (Tónica - I):* "Donde descansas, tu hogar." Cantar/tocar DO mayor y sentir reposo. | Representación: Metáfora espacial. |
| | | *El camino (Subdominante - IV):* "Te alejas de casa, hay movimiento." FA mayor. Sentir tensión media. | |
| | | *La tensión (Dominante - V):* "Estás lejos, necesitas volver." SOL mayor (o Sol7). Sentir la necesidad de resolución. | |
| | | *La sorpresa (vi - relativo menor):* "Un giro inesperado." LA menor. Sentir cambio emocional. | |
| | | **Juego "¿Adónde va?"**: Profesor toca 3 acordes y se detiene. Grupo debe cantar/intuir el 4o acorde. Entrenar el oído armónico. | Compromiso: Gamificación auditiva. |
| | | **Para Nivel A:** Pueden nombrar las funciones, tocar las progresiones en diferentes tonalidades. | |
| | | **Para Nivel B:** Tocan la progresión en su instrumento con cifrado. | |
| | | **Para Nivel C:** Cantan la fundamental de cada acorde (Do-Fa-Sol-La) como línea de bajo vocal. | Diferenciación: Cada nivel participa musicalmente. |
| **Desarrollo 2** | 30 min | **Análisis de canciones por progresión:** En equipos de 4-5, escuchar 3 canciones de diferentes géneros y: | Acción: Trabajo cooperativo. |
| | | 1) Identificar la progresión armónica (con cifrado en papel) | |
| | | 2) ¿Qué emoción transmite? | |
| | | 3) ¿A qué género pertenece? | |
| | | 4) Tocar/cantar la progresión como equipo | |
| | | **Canciones sugeridas:** Una pop (ej. "Someone Like You"), una latina (ej. "La Bamba" — I-IV-V), una mexicana (ej. "Cielito Lindo" — I-IV-V-I). | |
| | | Cada equipo presenta su análisis brevemente (2 min c/u). | Acción: Exposición oral + musical. |
| **Cierre** | 10 min | Reflexión: "¿Qué descubrieron sobre cómo funciona la música que escuchan?" Bitácora: escribir las progresiones de 3 canciones favoritas (tarea: identificarlas en casa). | |
| **Tarea web** | — | Sitio web → "Módulo 8: Armonía y Progresiones" — Infografía interactiva de progresiones comunes con audio. Quiz: escuchar fragmento → identificar progresión. | |

## Sesión 3 (Sem 2): El arte del arreglo — De la canción original a nuestra versión
### Arreglo musical, instrumentación y adaptación

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Diseñar** (Crear) un arreglo básico de una canción conocida adaptado a los recursos del grupo. |
| **Competencias MEFI** | CDBDHI10 (creatividad corporal-artística), CDBDHI17 |
| **SEL/CASEL** | Toma de decisiones responsable, Habilidades de relación |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"Mismo ingrediente, diferente platillo"**: Escuchar 3 versiones de la misma canción en estilos radicalmente diferentes (ej. "Bohemian Rhapsody" original → versión a cappella de Pentatonix → versión acústica). "¿Es la misma canción? ¿Qué cambió?" → Concepto de ARREGLO. | Compromiso: Revelación auditiva. |
| **Desarrollo 1** | 25 min | **Anatomía de un arreglo — Las preguntas del arreglista:** | Representación: Framework visual. |
| | | En pizarrón, esquema: | |
| | | 1) **¿Quién canta la melodía?** (Solista, coro al unísono, coro dividido) | |
| | | 2) **¿Qué pasa debajo de la melodía?** (Armonía: acordes, contramelodía, nota pedal) | |
| | | 3) **¿Cuál es el groove?** (Ritmo: patrón de batería/percusión, rasgueo) | |
| | | 4) **¿Quién hace el bajo?** (Línea de bajo: fundamental, walking, riff) | |
| | | 5) **¿Hay algo especial?** (Intro, solo, puente, final, efectos) | |
| | | 6) **¿Cuál es la forma?** (Intro-Verso-Coro-Verso-Coro-Puente-Coro-Outro) | |
| | | Demostrar con una canción simple (ej. "Happy Birthday"): ¿Cómo la arreglaríamos para nuestro grupo? Profesor construye el arreglo en vivo con aportes del grupo. | Acción: Co-creación guiada. |
| **Desarrollo 2** | 40 min | **Taller de arreglo en equipos:** | |
| | | Dividir en 3-4 equipos. Cada equipo recibe una canción sencilla (con melodía y acordes). Tienen 25 min para crear SU arreglo usando las 6 preguntas. | Acción: Autonomía creativa. Compromiso: Elección y ownership. |
| | | **Requisitos mínimos del arreglo:** | |
| | | - Al menos 2 líneas vocales (unísono + armonía o contramelodía) | |
| | | - Al menos 1 instrumento armónico (guitarra o piano) | |
| | | - Al menos 1 elemento rítmico (percusión, palmas, o chasquidos) | |
| | | - Al menos 1 momento dinámico (crescendo, sección suave, cambio de groove) | |
| | | Cada equipo presenta su arreglo al grupo (5 min c/u, incluye la explicación de sus decisiones). | Representación: Oral + musical. |
| | | Nivel A: Pueden escribir partitura/cifrado. Lideran la toma de decisiones musicales. | |
| | | Nivel B: Aportan ideas de oído, tocan su parte. | |
| | | Nivel C: Participan con voz o percusión, aportan ideas sobre forma y dinámicas. | |
| **Cierre** | 5 min | "¿Qué arreglo les gustó más? ¿Por qué?" Feedback entre equipos. Adelanto: "La próxima clase, cada equipo tomará una canción y creará un arreglo MÁS ambicioso." | |
| **Tarea web** | — | Sitio web → "Módulo 9: El Arte del Arreglo" — Tutorial de cómo construir un arreglo paso a paso. Ejemplos de arreglos corales + instrumentales con audio. Plantilla descargable para plan de arreglo. | |

## Sesión 4 (Sem 2): Lectura musical funcional — Lo que necesitas para crear
### Consolidación de lectura (partitura, cifrado, tablatura) al servicio de la creatividad

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Interpretar** (Comprender) notación musical básica en los 3 sistemas (pentagrama/cifrado/tablatura) y **utilizar** (Aplicar) la lectura para montar una pieza nueva sin depender del profesor. |
| **Competencias MEFI** | CDBDHI17, CG3 (tecnología para autoaprendizaje) |
| **SEL/CASEL** | Autogestión (autonomía de aprendizaje) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"Descifra el mensaje musical"**: Profesor escribe en pizarrón una melodía de 8 compases en 3 formatos: pentagrama, cifrado con ritmo, y tablatura. "Todos dicen lo mismo — ¿cuál entiendes mejor?" Cada alumno elige su sistema y lo toca/canta. | Representación: 3 sistemas simultáneos. Acción: Elección del alumno. |
| **Desarrollo 1** | 30 min | **Ruta de lectura diferenciada (3 estaciones simultáneas):** | |
| | | *Estación Pentagrama (Nivel A + quien quiera):* Lectura a primera vista de melodía + ritmo. Claves de Sol y Fa. Ejercicios de solfeo con signos Curwen. Dictado melódico: profesor toca → alumno escribe. | Diferenciación: Reto alto para avanzados. |
| | | *Estación Cifrado (Nivel B + quien quiera):* Leer cifrado americano (C, Dm, G7, etc.). Asociar cifrado con posiciones de guitarra/piano. Ritmo escrito con slash notation. Practicar montar una canción nueva SOLO con la hoja de cifrado. | Diferenciación: Puente informal → formal. |
| | | *Estación Tablatura/Ritmo (Nivel C + quien quiera):* Leer tablatura básica de guitarra. Leer ritmo con sílabas (ta, ti-ti). Seguir una línea de percusión escrita (x y o para golpes y silencios). | Diferenciación: Entrada amigable a la lectura. |
| | | Todos rotan por al menos 2 estaciones (15 min c/u). | Acción: Experiencia multi-sistema. |
| **Desarrollo 2** | 30 min | **Reto de autonomía — "Móntenla sin mí"**: | Compromiso: Independencia musical. |
| | | Profesor entrega a cada equipo una hoja con una canción nueva (sencilla) en cifrado + melodía + letra. SIN demostración previa. Equipos tienen 20 min para montar la canción SOLOS usando su lectura musical y negociando roles. | |
| | | Profesor observa y apoya SOLO si piden ayuda — el objetivo es la autonomía. | |
| | | Presentación de cada equipo (2 min c/u). | |
| | | Nivel A: Pueden montar con partitura completa. Dirigen a su equipo. | |
| | | Nivel B: Usan cifrado + oído. | |
| | | Nivel C: Siguen la tablatura/ritmo, cantan la melodía por imitación de un compañero. | |
| **Cierre** | 10 min | Reflexión: "¿Pudieron montar una canción sin que yo les enseñara? ¿Qué necesitaron?" El poder de la lectura musical = independencia. Meta del sitio web: convertirse en su "profesor disponible 24/7". | |
| **Tarea web** | — | Sitio web → "Módulo 10: Lectura Musical" — Ejercicios interactivos de lectura en los 3 sistemas. Quiz de identificación de notas. Karaoke de solfeo con audio guía. | |
