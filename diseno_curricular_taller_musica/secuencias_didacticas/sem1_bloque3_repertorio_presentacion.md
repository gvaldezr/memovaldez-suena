## Sesión 9: Montaje del repertorio I — Aprender las piezas
### Primera lectura y aprendizaje de las 3-4 canciones seleccionadas

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | Calentamiento vocal + rítmico estándar (ya es rutina a estas alturas). Breve charla motivacional: "Faltan 6 semanas para el escenario." | Compromiso: Meta clara y tangible. |
| **Desarrollo** | 65 min | **Pieza 1 (~20 min):** Aprender melodía por imitación → agregar letra → cifrado para instrumentistas. Asignar voces (soprano/alto o Voz Azul/Roja). | Representación: Imitación + visual. |
| | | **Pieza 2 (~20 min):** Mismo proceso. Si es más rítmica (ej. "El Burrito Sabanero"), enfocar en groove de percusión. | Acción: Percusionistas protagonizan. |
| | | **Pieza 3 (~20 min):** Si es más compleja (ej. "Carol of the Bells"), solo melodía principal hoy. Nivel A trabaja la segunda voz. | Diferenciación: Reto apropiado por nivel. |
| | | *Rotación de roles instrumentales:* Asegurar que cada alumno sabe qué toca en cada pieza. Algunos pueden cambiar de rol entre canciones. | Acción: Variedad de roles. |
| **Cierre** | 5 min | **Checklist personal:** "¿Qué pieza me sé mejor? ¿Cuál necesito practicar en casa?" Recordar sitio web con materiales de práctica. | |
| **Tarea web** | — | Practicar en casa con audios de referencia y cifrado del sitio web. | |

#### Diferenciación

| Nivel A | Nivel B | Nivel C |
|---------|---------|---------|
| Aprenden partitura completa de las 3 piezas. Segunda voz, arreglos complejos, solos potenciales. | Cifrado + tabs para instrumento. Melodía vocal por imitación + letra. | Melodía principal por repetición. Percusión corporal o menor en partes rítmicas. Coro al unísono en lo más accesible. |

## Sesión 10: Montaje del repertorio II — Profundizar y pulir
### Trabajo por secciones y atención a detalles

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | Calentamiento vocal enfocado en las tonalidades del repertorio. Vocalización en las escalas de las canciones. | |
| **Desarrollo** | 65 min | **Trabajo por estaciones rotativas (3 estaciones, ~20 min c/u):** | Acción: Grupos pequeños, atención personalizada. |
| | | *Estación A — Voces:* Profesor trabaja afinación, entradas, armonía de la pieza más difícil. | |
| | | *Estación B — Instrumentos armónicos:* Guitarras y piano trabajan transiciones entre canciones, cambios de acorde limpios, patrones rítmicos específicos. (Alumno Nivel A como líder/tutor). | Compromiso: Aprendizaje cooperativo. |
| | | *Estación C — Ritmo y percusión:* Batería, cajón, percusiones latinas definen patrones para cada pieza. Incluye palmas y percusión corporal para momentos específicos. | Acción: Nivel C protagoniza aquí. |
| | | **Últimos 10 min: Ensayo tutti** de la pieza que más necesita trabajo. | |
| **Cierre** | 5 min | Feedback del profesor: "Lo que ya suena increíble / lo que necesitamos refinar." Motivación. | |
| **Tarea web** | — | Sitio web: Audio de la segunda voz aislada para practicar en casa. Tutorial de la parte de guitarra de la pieza más difícil. | |

## Sesión 11: Montaje del repertorio III — Expresión y narrativa del show
### Dinámicas, transiciones y concepto escénico

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"Visualización del concierto"**: Ojos cerrados. "Imaginen que están en el escenario. El público está ahí. La primera nota suena..." Ejercicio de mentalización que usan músicos profesionales. | Compromiso: Conexión emocional + manejo de nervios. |
| **Desarrollo** | 65 min | **Narrativa del show (20 min):** Definir el ORDEN de las canciones (dramaturgia del concierto): | Compromiso: Autonomía — alumnos deciden. |
| | | 1) Apertura energética (ej. "All I Want for Christmas") — captar atención | |
| | | 2) Pieza emotiva/suave (ej. "Noche de Paz" a cappella) — contraste | |
| | | 3) Pieza regional/divertida (ej. "El Burrito Sabanero") — identidad + alegría | |
| | | 4) Cierre impactante (ej. "Carol of the Bells" o medley final) — wow factor | |
| | | **Transiciones:** ¿Cómo pasamos de una canción a otra? ¿Aplausos? ¿Encadenadas? ¿Alguien presenta? | |
| | | **Mapa de dinámicas del show (20 min):** Dibujar la curva emocional del concierto completo en pizarrón. Marcar dinámicas de cada pieza. | Representación: Visual (mapa dramático). |
| | | **Ensayo con movimiento escénico (25 min):** ¿Dónde se para cada sección? ¿Cómo entran? ¿Cómo salen? ¿Hay movimiento coreográfico en alguna pieza? ¿Quién presenta al público? Ensayar entradas y salidas. | Acción: Corporal + espacial. |
| **Cierre** | 5 min | Asignar responsabilidades: presentador(es), utilería, vestuario (si aplica — color unificado). | |
| **Tarea web** | — | Repasar TODAS las piezas con los materiales del sitio. | |

## Sesión 12: Ensayo general I — Flujo completo
### Primera corrida completa del programa

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | Calentamiento vocal + corporal intenso. Ejercicio de enfoque: "De aquí en adelante somos un ensamble profesional. Nos tratamos como profesionales." | Compromiso: Identidad de grupo. |
| **Desarrollo** | 70 min | **Corrida completa del programa** en el orden definitivo, con transiciones, dinámicas, movimiento escénico. SIN PARAR (como si fuera el concierto). | Acción: Simulación real. |
| | | **Grabación** (celular/cámara) para auto-evaluación. | |
| | | **Revisión inmediata (20 min):** Ver/escuchar fragmentos de la grabación. Lista de 3 cosas que funcionan + 3 cosas a mejorar. Trabajo focalizado en las 3 mejoras. | Compromiso: Auto-evaluación basada en evidencia. |
| **Cierre** | 10 min | **Coevaluación breve:** Cada sección evalúa a otra: "¿Qué les salió muy bien? ¿Qué sugerencia les dan?" Con respeto y constructividad. | SEL: Conciencia social + comunicación constructiva. |
| **Tarea web** | — | Práctica individual intensiva. Memorizar letras si aún no. | |

## Sesión 13: Ensayo general II — Pulido final
### Detalle, confianza y manejo de nervios

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **"Respiración anti-nervios"**: Técnicas de respiración 4-7-8 para manejo de ansiedad escénica. "Los nervios son energía — la canalizamos." | SEL: Autogestión emocional. |
| **Desarrollo** | 70 min | **Corrida completa #2** — de inicio a fin, orden final. | |
| | | Si hay errores, NO parar — aprender a recuperarse en vivo. "En el escenario no hay borrador." | Compromiso: Resiliencia musical. |
| | | **Trabajo quirúrgico (30 min):** Solo las partes que fallaron. Repetir hasta dominar. | |
| | | **Corrida completa #3** — la definitiva. Celebrar lo que suena bien. | |
| **Cierre** | 10 min | **Círculo de confianza:** De pie en círculo. Cada alumno dice una palabra que describa cómo se siente sobre la presentación de mañana/próxima semana. Profesor cierra con mensaje de confianza: "Ya están listos. Lo que construimos es real." | Compromiso: Comunidad, apoyo mutuo. |
| **Tarea web** | — | Repaso final individual. Visualización del concierto exitoso. | |

## Sesión 14: 🎄 PRESENTACIÓN DE NAVIDAD
### Producto integrador del Semestre 1

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Crear/Interpretar** una presentación musical colectiva que integre técnica vocal, instrumental, expresiva y escénica. **Evaluar** (autoevaluar) el desempeño personal y grupal. |
| **Competencias MEFI** | CDBDHI5 + CDBDHI10 + CDBDHI17 (las 3 integradas) |
| **SEL/CASEL** | Todas las competencias CASEL demostradas en acción |

#### Estructura

| Momento | Tiempo | Actividad |
|---------|--------|-----------|
| **Pre-show** | 20 min | Calentamiento vocal grupal. Círculo de energía ("Mano al centro, 1-2-3, ¡VAMOS!"). Verificar afinación, instrumentos, posiciones. |
| **Presentación** | 40-50 min | Ejecución del programa completo ante público (compañeros, profesores, familias si aplica). 3-4 piezas con transiciones, dinámicas, movimiento. |
| **Post-show** | 20 min | **Celebración** — reconocimiento del logro grupal. Fotos. **Autoevaluación escrita** (15 min): formulario con preguntas de reflexión: |
| | | 1) ¿Qué sentí antes, durante y después de la presentación? |
| | | 2) ¿Qué salió mejor de lo esperado? |
| | | 3) ¿Qué haría diferente? |
| | | 4) ¿Qué aprendí de mí este semestre a través de la música? |
| | | 5) Del 1 al 10, ¿qué tanto disfruté el proceso? |

#### Evaluación sumativa
- **Rúbrica de presentación** (evaluación grupal + individual) — 20% de calificación semestral
- **Autoevaluación reflexiva** — parte del portafolio
- **Coevaluación** — "¿A quién reconoces por su esfuerzo este semestre?"
