# 🎵 Semestre 1 — Bloque 1: Diagnóstico y Fundamentos Musicales
## Sesiones 1–4 | "Desarrollo Físico y Artístico"

> **Eje:** Establecer el punto de partida y construir los cimientos musicales comunes para un grupo heterogéneo.
> **Hilo conductor:** "Todos hacemos música — descubramos juntos de qué somos capaces."

---

## Visión general del bloque

| Aspecto | Detalle |
|---------|---------|
| **Sesiones** | 4 (360 min total) |
| **Competencias MEFI** | CDBDHI5 (interacción social), CDBDHI17 (emociones por medio del arte) |
| **Genéricas** | CG1 (comunicación), CG8 (trabajo colaborativo), CG10 (gestión emocional) |

## Sesión 1: ¿Quiénes somos musicalmente?
### Diagnóstico y comunidad

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Identificar** (Recordar) el nivel musical propio y el del grupo, y **reconocer** (Comprender) la diversidad como recurso del ensamble. |
| **Competencias MEFI** | CDBDHI5, CDBDHI17 |
| **SEL/CASEL** | Autoconciencia, Conciencia social |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Círculo de sonido"**: Sentados en círculo, cada alumno dice su nombre y hace un sonido/ritmo que lo represente (voz, palmas, instrumento). El grupo lo repite. Sin juicio — todo vale. | **Compromiso:** Baja amenaza, alta pertenencia. **Representación:** Modelo auditivo + visual (gestos). |
| **Desarrollo 1** | 25 min | **Diagnóstico musical lúdico** (NO examen escrito). 4 estaciones rotativas (6 min c/u): | |
| | | *Estación 1 — Ritmo:* Repetir patrones rítmicos progresivos con palmas (profesor demuestra → alumno repite). De 4 pulsos simples a patrones sincopados. | **Acción:** Palmas (todos pueden). **Representación:** Auditivo + visual (profesor modela). |
| | | *Estación 2 — Voz:* Cantar una melodía conocida (ej. "Cielito Lindo" o "Let It Be"). Evaluar afinación relativa, rango, confianza. | **Compromiso:** Canción conocida = bajo riesgo. |
| | | *Estación 3 — Instrumento:* Si traen instrumento, tocar algo que sepan (lo que sea). Si no traen, explorar percusiones del aula. | **Acción:** Libertad total de expresión. |
| | | *Estación 4 — Lectura:* Identificar notas en pentagrama básico, leer un cifrado, o seguir una tablatura. Tarjetas con niveles progresivos. | **Representación:** Visual en 3 sistemas (partitura/cifrado/tab). |
| **Desarrollo 2** | 25 min | **"Ritmo grupal instantáneo"**: Profesor dirige un body percussion groove simple (stomps + palmas + chasquidos). Capas progresivas. Ejemplo: *We Will Rock You* (stomp-stomp-clap). **Todos participan desde el nivel que tengan.** | **Acción:** Percusión corporal = instrumento universal. **Compromiso:** Canción icónica, resultado grupal inmediato. |
| **Cierre** | 15 min | **Reflexión en parejas** (2 min): "¿Qué descubriste de ti hoy?" → Compartir voluntario al grupo (3 min). **Presentación del taller**: qué haremos, presentaciones finales, sitio web, cómo se evalúa (progresión, no perfección). Introducir la **Bitácora Musical** (cuaderno o digital). | **Compromiso:** Expectativas claras, transparencia evaluativa. |
| **Tarea web** | — | Explorar el sitio web → Sección "¿Por dónde empiezo?" Responder autoevaluación diagnóstica online. | **Representación:** Recurso alterno digital. |

#### Diferenciación por nivel

| Nivel A (académicos) | Nivel B (autodidactas) | Nivel C (principiantes) |
|---|---|---|
| En estaciones, demuestran todo. Pueden ayudar como "mentores" en Estación 4. En ritmo grupal: llevan la base rítmica compleja o la melodía. | En estaciones, muestran lo que saben (tabs, oído). En ritmo grupal: aportan riffs o variaciones. | En estaciones, exploran sin presión. En ritmo grupal: stomps y palmas básicos — participación garantizada. |

#### Materiales y recursos
- Tarjetas de lectura musical (3 niveles: pentagrama / cifrado / tablatura)
- Percusiones menores del aula (claves, panderetas, maracas, cajón)
- Ficha de diagnóstico del profesor (checklist observacional, NO calificado)
- Sitio web: Sección "¿Por dónde empiezo?" + autoevaluación diagnóstica

#### Evaluación formativa
- **Instrumento:** Checklist observacional del profesor (ritmo ✓/△/✗, voz ✓/△/✗, instrumento ✓/△/✗, lectura ✓/△/✗, actitud ✓/△/✗)
- **Propósito:** Mapear al grupo en niveles A/B/C. NO se califica — se usa para planificar diferenciación.

## Sesión 2: El pulso que nos une
### Ritmo, tempo y subdivisión

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Ejecutar** (Aplicar) patrones rítmicos en diferentes tempos y **distinguir** (Comprender) entre pulso, acento y subdivisión. |
| **Competencias MEFI** | CDBDHI5, CDBDHI10 |
| **SEL/CASEL** | Autogestión (control del tempo personal), Habilidades de relación (sincronía grupal) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Juego del director"**: Un alumno marca el pulso con palmas (cambiando velocidad). El grupo debe seguirlo con stomps. Quien se desincronice, pasa al centro a dirigir. Lúdico, sin eliminación. | **Compromiso:** Juego competitivo amigable. **Acción:** Corporal, sin instrumento. |
| **Desarrollo 1** | 25 min | **Conceptos en acción** (NO pizarrón expositivo): | |
| | | *Pulso:* Caminar por el salón al beat de música grabada (diferentes géneros: cumbia, rock, electrónica). Sentir el pulso en el cuerpo. | **Representación:** Kinestésico + auditivo. |
| | | *Acento:* Marcar el tiempo fuerte con stomp, los débiles con palmas. Primero en 4/4, luego en 3/4 (vals). | **Representación:** Corporal + auditivo. |
| | | *Subdivisión:* Con claves/palmas, dividir el pulso en 2 (corcheas) y 4 (semicorcheas). Usar sílabas rítmicas: "ta" (negra), "ti-ti" (corcheas), "tiki-tiki" (semicorcheas). → Método Kodály adaptado. | **Representación:** Oral + corporal + visual (pizarrón con símbolos). |
| **Desarrollo 2** | 30 min | **"Batucada express"**: Dividir grupo en 4 secciones (percusión corporal + instrumentos disponibles). Cada sección tiene un patrón rítmico diferente (ostinato). Profesor dirige la entrada por capas. Construir groove colectivo. | |
| | | *Sección 1 (grave):* Stomp o cajón — pulso base. | **Nivel C:** Patrón más simple. |
| | | *Sección 2 (medio):* Palmas o claves — contratiempo. | **Nivel B:** Patrón intermedio. |
| | | *Sección 3 (agudo):* Chasquidos o pandereta — subdivisión. | **Nivel A:** Patrón más complejo + improvisación. |
| | | *Sección 4 (melódica):* Quien traiga instrumento, agrega nota pedal o riff sobre la base rítmica. | **Nivel A/B:** Aportan textura melódica. |
| | | Rotar secciones para que todos experimenten cada capa. | **DUA Acción:** Múltiples roles disponibles. |
| **Cierre** | 10 min | **Bitácora Musical:** Escribir/dibujar "¿Qué ritmo llevo dentro?" Reflexión libre sobre lo vivido. Compartir voluntario. Mención del sitio web: "Módulo de Ritmo" para profundizar. | **Compromiso:** Conexión emocional. **Representación:** Texto o dibujo (opción). |
| **Tarea web** | — | Sitio web → "Módulo 1: Ritmo" — Ejercicios interactivos de identificación de pulso y subdivisión. Juego de matching rítmico. | **Representación:** Digital, auto-paced. |

#### Diferenciación por nivel

| Nivel A | Nivel B | Nivel C |
|---------|---------|---------|
| Patrones con sincopa y desplazamiento. Pueden improvisar fills. Leen la partitura rítmica del pizarrón. | Patrones de contratiempo. Leen cifrado rítmico simplificado. Aportan ideas de sus canciones conocidas. | Pulso básico (negras). Stomp-stomp-clap. Participan en la sección más estable. Sílabas rítmicas como guía. |

#### Materiales y recursos
- Bocina bluetooth para música grabada (playlist de 3 géneros distintos para caminar al pulso)
- Percusiones del aula: claves, cajón, panderetas, maracas, bongós
- Pizarrón: notación rítmica simplificada con colores (negra=azul, corchea=verde, semicorchea=rojo)
- Sitio web: Módulo 1 — Ritmo (ejercicios interactivos)

#### Evaluación formativa
- **Observación directa:** ¿El alumno mantiene el pulso? ¿Distingue acento? ¿Ejecuta su ostinato con estabilidad?
- **Autoevaluación rápida** (pulgar arriba/medio/abajo): "¿Pude mantener mi parte en la batucada?"

## Sesión 3: La voz de todos — Melodía y escala
### Fundamentos melódicos y primera experiencia coral

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Entonar** (Aplicar) una melodía simple por imitación y **explicar** (Comprender) la relación entre notas en una escala mayor. |
| **Competencias MEFI** | CDBDHI17, CDBDHI10 |
| **SEL/CASEL** | Autoconciencia (descubrir la propia voz), Autogestión (superar vergüenza) |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 15 min | **"Calentamiento vocal lúdico"**: Ejercicios disfrazados de juego — sirenas (glissando ascendente/descendente), "el mosquito" (zumbido en mmm cambiando altura), "la moto" (vibración de labios con melodía). Todos de pie, en círculo. Nadie "canta" todavía — solo hacemos sonidos. | **Compromiso:** Sin etiqueta de "cantar" = menos miedo. **Acción:** Corporal + vocal, progresivo. |
| **Desarrollo 1** | 25 min | **La escala como escalera**: | |
| | | *Visual:* En pizarrón, dibujar escalera de 8 peldaños = escala de Do mayor. Cada peldaño con nombre (Do-Re-Mi...) y color. | **Representación:** Visual + colores. |
| | | *Corporal:* Cantar la escala subiendo/bajando, acompañando con movimiento de manos (signos Curwen/Kodály): Do=puño a la cintura → Re=mano inclinada → Mi=mano plana... | **Representación:** Kinestésico + visual + auditivo. **Acción:** Todo el cuerpo participa. |
| | | *Instrumental:* Nivel A/B toca la escala en su instrumento. Nivel C la canta o la toca en percusión de placas (xilófono si hay) o sigue con palmas el ritmo. | **Diferenciación:** Cada nivel con su medio de expresión. |
| | | **Juego "El director loco"**: Profesor señala peldaños aleatorios de la escalera → grupo canta la nota. Acelera. Los errores son divertidos, no penalizados. | **Compromiso:** Gamificación, humor. |
| **Desarrollo 2** | 30 min | **Primera experiencia coral — Canon a 2 voces**: | |
| | | Enseñar "Frère Jacques / Martinillo" por imitación (frase por frase). Cuando todos la dominan, dividir en 2 grupos para canon. | **Representación:** Imitación (sin partitura al inicio). |
| | | *Nivel A:* Pueden llevar la segunda entrada, sostener su línea con independencia. | |
| | | *Nivel B:* Primera entrada con apoyo del piano/guitarra. | |
| | | *Nivel C:* Cantan con el grupo más grande, apoyados por los demás. | |
| | | **Variación:** Agregar percusión corporal (palmas en pulso) mientras cantan. Los que no quieran cantar pueden hacer la percusión. | **Acción:** Opción alternativa para quien no se atreva a cantar aún. |
| **Cierre** | 10 min | **Reflexión guiada:** "¿Cómo se sintió cantar con otros? ¿Fue diferente a cantar solo?" Bitácora: dibujar o escribir la experiencia. Adelanto: "La próxima sesión vamos a hacer MÚSICA DE VERDAD juntos — traigan sus instrumentos." | **Compromiso:** Conexión emocional, anticipación. |
| **Tarea web** | — | Sitio web → "Módulo 2: Melodía y Escala" — Video explicativo de la escala mayor con colores. Ejercicio interactivo de identificación de notas (ascendente/descendente). | |

#### Materiales y recursos
- Pizarrón con escalera de colores dibujada (o proyección)
- Referencia de signos Curwen impresos o en pantalla
- Piano del aula para referencia de afinación
- Letra de "Martinillo" / "Frère Jacques" impresa (con notas en cifrado encima)
- Sitio web: Módulo 2 — Melodía y Escala

#### Evaluación formativa
- **Observación:** ¿El alumno entona la escala con aproximación? ¿Mantiene su línea en el canon?
- **Termómetro emocional** (al cierre): Señalar del 1-5 "¿Qué tan cómodo me sentí cantando?"

## Sesión 4: Nuestro primer ensamble
### Integración rítmica + melódica + primer arreglo grupal

| Elemento | Descripción |
|----------|-------------|
| **Objetivo (Bloom)** | **Ejecutar** (Aplicar) una pieza musical sencilla integrando voz, ritmo e instrumentos, y **valorar** (Evaluar) el aporte individual al resultado colectivo. |
| **Competencias MEFI** | CDBDHI5, CDBDHI10, CDBDHI17 |
| **SEL/CASEL** | Habilidades de relación (trabajo en equipo musical), Toma de decisiones responsable |

#### Estructura de 90 minutos

| Momento | Tiempo | Actividad | DUA |
|---------|--------|-----------|-----|
| **Apertura** | 10 min | **Calentamiento rítmico-vocal:** Repaso rápido de sílabas rítmicas (ta, ti-ti, tiki-tiki) + calentamiento vocal (sirenas + escala con Curwen). 5 min cuerpo, 5 min voz. | **Representación:** Multi-sensorial (consolidación de sesiones anteriores). |
| **Desarrollo 1** | 25 min | **Aprendizaje de la pieza — "Lean on Me" (Bill Withers)** o pieza seleccionada por el profesor. Elegida por: melodía simple, mensaje emocional potente, funciona a 2 voces, permite ensamble heterogéneo. | **Compromiso:** Canción significativa, generacionalmente adaptable. |
| | | *Paso 1:* Escuchar la canción original (versión audio). Identificar pulso, estructura (verso-coro). | **Representación:** Auditivo primero. |
| | | *Paso 2:* Aprender la melodía principal por imitación (frase por frase). Profesor canta → grupo repite. | **Representación:** Imitación (tradición oral). |
| | | *Paso 3:* Agregar letra (proyectada o impresa). Cantar con letra. | **Representación:** Visual + auditivo. |
| **Desarrollo 2** | 35 min | **Armar el ensamble por secciones:** | |
| | | *Voces (todos):* Melodía del coro al unísono. Los que se animen, melodía del verso. | **Acción:** Todos cantan algo. |
| | | *Guitarra/Piano (Nivel A/B):* Acordes del cifrado (Do-Sol-Lam-Fa o equivalente). Nivel A: patrón rítmico completo. Nivel B: rasgueo básico o acordes en blancas. | **Representación:** Cifrado en pizarrón. |
| | | *Bajo (Nivel A/B):* Línea de bajo (fundamentales en negras → walking bass para avanzados). | **Diferenciación:** Complejidad progresiva. |
| | | *Batería/Percusión (todos los niveles):* Nivel C: palmas en pulso o pandereta. Nivel B: cajón con patrón básico. Nivel A: batería completa o congas con patrón latino. | **Acción:** Percusión como puerta de entrada universal. |
| | | **Ensamblar por capas:** 1) Solo ritmo → 2) Agregar bajo → 3) Agregar armonía (guitarra/piano) → 4) Agregar voz → 5) Juntos. Repetir el coro varias veces hasta que suene cohesivo. | |
| | | 💡 **Momento mágico:** La primera vez que suena "bien" juntos. El profesor para, reconoce el logro: "¿Escucharon eso? Eso lo hicimos TODOS." | **Compromiso:** Experiencia cumbre, motivación intrínseca. |
| **Cierre** | 10 min | **Reflexión grupal:** "¿Qué pasó cuando todos tocamos juntos? ¿Qué se necesita para que funcione?" Introducir conceptos: escucha activa, balance, dinámica. | |
| | | **Bitácora:** "Mi primer ensamble — ¿Qué sentí? ¿Qué aporté? ¿Qué quiero mejorar?" | **Compromiso:** Metacognición musical. |
| | | **Adelanto Bloque 2:** "Ya sabemos que podemos hacer música juntos. Ahora vamos a hacerla MEJOR — técnica vocal, ensamble más pulido, y empezamos a elegir repertorio para Navidad." | |
| **Tarea web** | — | Sitio web → "Módulo 3: Mi primer ensamble" — Audio de referencia de la pieza, cifrado/tablatura, letra, video tutorial de los acordes. | |

#### Diferenciación por nivel

| Nivel A | Nivel B | Nivel C |
|---------|---------|---------|
| Partitura completa o arreglo complejo. Pueden improvisar sobre la estructura. Rol de líder de sección o co-director. | Cifrado + tab. Tocan acordes o línea de bajo simplificada. Cantan con confianza. | Percusión corporal o menor. Cantan el coro por imitación. Palmas en pulso. Participación garantizada sin lectura musical. |

#### Materiales y recursos
- Audio de "Lean on Me" (o pieza elegida) en bocina
- Cifrado proyectado/impreso (acordes + letra)
- Tablatura para guitarra y bajo (impresa o en sitio web)
- Instrumentos del aula: piano, batería, percusiones
- Sitio web: Módulo 3 — tutorial de acordes, audio de referencia

#### Evaluación formativa
- **Observación directa:** ¿El alumno mantiene su parte en el ensamble? ¿Escucha a los demás? ¿Se ajusta al grupo?
- **Autoevaluación con semáforo:** Verde = "Pude hacer mi parte bien" / Amarillo = "Me costó pero lo intenté" / Rojo = "Necesito más práctica"
- **Evaluación de bloque:** Checklist de progresión vs. diagnóstico de Sesión 1 (sin calificación formal)
