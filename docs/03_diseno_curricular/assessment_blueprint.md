# 📋 Assessment Blueprint: Taller de Música

> **Taller de Música — Bachillerato UADY MEFI**
> **Diseño integral de evaluación — Semestres 1 y 2**
> **Asignaturas:** Desarrollo físico y artístico (Sem 1) | Creatividad en movimiento (Sem 2)
> **Estructura:** 14 sesiones/semestre × 90 min | 28 sesiones totales

---

## 1. Filosofía de Evaluación

### Principios Rectores

| Principio | Aplicación en el taller |
|-----------|------------------------|
| **Assessment auténtico** | Se evalúa el desempeño musical real: cantar, tocar, presentar, ensayar, colaborar — no exámenes teóricos |
| **Proceso > Producto** | 70% del peso es proceso (participación, progresión, reflexión). 30% es producto (presentaciones, portafolio) |
| **Evaluación de progresión** | Se mide cuánto avanzó el alumno desde su punto de partida, no su nivel absoluto |
| **Inclusiva y diferenciada** | Tres niveles de entrada (A/B/C) con expectativas ajustadas pero equitativas |
| **Formativa primero** | La evaluación sirve para MEJORAR, no solo para calificar. Feedback constante |
| **Multiagente** | Docente (80%), autoevaluación (10%), coevaluación (10%) |
| **Multi-evidencia** | Observación directa, portafolio, presentación en vivo, reflexiones escritas, instrumentos escalados |

## 3. Distribución de Pesos — Fórmula de Calificación Final

```
CALIFICACIÓN FINAL = PROCESO (70%) + PRODUCTO (30%)
```

### Desglose detallado:

| Componente | Rúbrica | Peso | Tipo |
|------------|---------|------|------|
| **PROCESO (70%)** | | | |
| Participación y proceso | Rúbrica de Participación | 35% | Formativa continua → sumativa |
| Habilidades musicales (progresión) | Rúbrica de Habilidades | 25% | Formativa → 3 cortes sumativos |
| Autoevaluación | Instrumentos de Autoevaluación | 5% | Formativa (3 aplicaciones) |
| Coevaluación | Instrumentos de Coevaluación | 5% | Formativa (2 aplicaciones) |
| **PRODUCTO (30%)** | | | |
| Presentación final | Rúbrica de Presentación | 20% | Sumativa (1 por semestre) |
| Portafolio/Bitácora musical | Rúbrica de Portafolio | 10% | Sumativa (entrega final semestre) |
| **TOTAL** | | **100%** | |

### Fórmula explícita:

```
Cal = (Participación × 0.35) + (Habilidades × 0.25) + (Autoeval × 0.05) + 
      (Coeval × 0.05) + (Presentación × 0.20) + (Portafolio × 0.10)
```

> ⚠️ Verificación MEFI: Proceso = 35% + 25% + 5% + 5% = **70%** ✓ (dentro del rango 60-80%)
> Producto = 20% + 10% = **30%** ✓ (dentro del rango 20-40%)

## 6. Criterios de Acreditación

### Calificación Mínima Aprobatoria: **6.0**

| Requisito | Descripción |
|-----------|-------------|
| **Asistencia mínima** | ≥70% de las sesiones del semestre (≥10 de 14) |
| **Participación en presentación** | Haber participado en la presentación final (salvo causa justificada con evidencia alternativa) |
| **Entrega de portafolio** | Haber entregado el portafolio/bitácora (puede ser incompleto pero entregado) |
| **Autoevaluaciones** | Haber completado al menos 2 de las 3 autoevaluaciones |

### Casos Especiales

| Caso | Política |
|------|----------|
| **Alumno que no puede participar en la presentación** (lesión, ausencia justificada) | Evaluación alternativa: grabación individual + reflexión escrita ampliada. Peso de presentación se redistribuye: 10% a habilidades, 10% a portafolio |
| **Alumno con necesidades especiales** | Adaptación curricular significativa según diagnóstico. Mismas rúbricas con ajustes en evidencias observables, documentados en expediente |
| **Alumno que entra tarde al semestre** | Diagnóstico inmediato al integrarse. Evaluación prorrateada según sesiones cursadas. Mínimo 70% de las sesiones restantes |
| **Alumno que cambia de nivel (A/B/C)** | Reclasificación permitida en cualquier corte. La evaluación de habilidades se ajusta al nuevo nivel desde el momento del cambio |

## 7. Política de Evaluación Diferenciada

### El Problema

En un grupo con músicos de conservatorio y principiantes absolutos, ¿cómo es justo evaluarlos con la misma rúbrica?

### La Solución: Evaluación de Progresión Relativa

```
PROGRESIÓN = Nivel actual - Nivel inicial (del mismo alumno)
```

| Principio | Implementación |
|-----------|---------------|
| **Línea base individual** | El diagnóstico de la Sesión 1 establece el punto de partida de CADA alumno |
| **Expectativas diferenciadas** | Las rúbricas de habilidades tienen descriptores diferentes para Nivel A, B y C |
| **Mismos criterios de proceso** | Participación, actitud, colaboración y portafolio se evalúan IGUAL para todos |
| **Progresión > Nivel absoluto** | Un principiante que logra cantar afinado en unísono obtiene "Sobresaliente" en entonación, aunque un académico que hace lo mismo obtiene "En desarrollo" |
| **Techo abierto** | Si un alumno de Nivel C progresa tanto que sus habilidades alcanzan el Nivel B, se reclasifica y se evalúa con los criterios de B |

### Ejemplo Práctico

| Alumno | Nivel | Diagnóstico (Sesión 1) | Corte 2 (Sesión 10) | Evaluación |
|--------|-------|------------------------|---------------------|------------|
| **Vale** (Académica) | A | Lee partitura, toca piano, buena afinación | Misma lectura, misma afinación, no exploró dirección ni arreglos | **En desarrollo** — no progresó |
| **Santi** (Autodidacta) | B | Toca guitarra de oído, no lee partitura | Toca guitarra + lee cifrado + empezó a leer pentagrama | **Sobresaliente** — progresión notable |
| **Majo** (Principiante) | C | No toca nada, desafina al cantar | Mantiene pulso con claves, canta afinada en unísono | **Sobresaliente** — progresión extraordinaria |

> 💡 Este sistema incentiva al **músico avanzado a salir de su zona de confort** (si se queda cómodo, no obtiene "Sobresaliente") y **protege al principiante** de ser castigado por su punto de partida.

## 8. Instrumento de Evaluación Diagnóstica (Sesión 1)

### Objetivo
Clasificar a cada alumno en Nivel A, B o C y establecer su línea base de habilidades.

### Formato: Actividad Grupal + Muestreo Individual (40-50 min)

#### Parte 1 — Grupal (15 min)

| Actividad | Qué evalúa | Cómo registrar |
|-----------|------------|----------------|
| **"Mi historia musical"**: Cada alumno dice su nombre, si toca algo, dónde aprendió, qué música le gusta | Experiencia previa, perfil, actitud | Notas rápidas en lista |
| **Eco rítmico**: El docente palmea un patrón, el grupo repite. Progresión de dificultad (negras → corcheas → síncopas) | Sentido rítmico del grupo | Observación general: ¿quién sigue? ¿quién se pierde? |
| **Cantar juntos** "Las mañanitas" o canción universalmente conocida | Entonación grupal, disposición a cantar | Observación: ¿quién canta con confianza? ¿quién susurra? ¿quién no canta? |

#### Parte 2 — Muestreo Individual / Grupos Pequeños (25-30 min)

Mientras el grupo hace una actividad libre (escuchar y comentar una pieza), el docente llama de 3 en 3 para evaluación rápida:

| Actividad | Qué evalúa | Tiempo |
|-----------|------------|--------|
| "Toca/canta algo que sepas" | Nivel técnico actual | 1-2 min |
| Repetir un patrón melódico cantado por el docente (3-5 notas) | Entonación y oído | 30 seg |
| "¿Puedes leer esto?" (mostrar pentagrama con notas en escala de Do) | Lectura musical | 30 seg |
| "¿Conoces estos símbolos?" (clave de Sol, figuras rítmicas, cifrado C-G-Am) | Alfabetización musical | 30 seg |

#### Parte 3 — Clasificación (post-sesión)

El docente clasifica en base a la siguiente matriz:

| Criterio | Nivel C (Principiante) | Nivel B (Autodidacta) | Nivel A (Académico) |
|----------|----------------------|----------------------|---------------------|
| ¿Toca un instrumento? | No | Sí (aprendió solo/YouTube) | Sí (clases formales) |
| ¿Lee partitura? | No | No (usa tabs/cifrado/oído) | Sí |
| ¿Entonación? | Muy desafinado o no canta | Entonación intuitiva (algunas notas) | Buena afinación consciente |
| ¿Sentido rítmico? | Débil | Bueno de forma intuitiva | Bueno y formal |
| ¿Vocabulario musical? | Ninguno | Informal (acorde, rasgueo, riff) | Formal (escala, compás, dinámica) |

> Si un alumno está en el límite entre dos niveles, clasificar en el inferior y ajustar en el Corte 1.

## 9. Flujo de Retroalimentación

```
              ┌──────────────────────────────────────┐
              │         CICLO DE FEEDBACK             │
              │                                      │
  Sesión ──►  │  Observación ──► Registro ──►        │
              │      │                                │
              │      ▼                                │
              │  Feedback oral inmediato              │
              │  ("Oye, buen trabajo en el ritmo"     │
              │   "Intenta escuchar más al bajo")     │
              │      │                                │
              │      ▼                                │
  Corte ──►   │  Evaluación formal ──► Calificación  │
              │      │                                │
              │      ▼                                │
              │  Retroalimentación escrita            │
              │  (nota en portafolio o Google Forms)  │
              │      │                                │
              │      ▼                                │
              │  Autoevaluación del alumno            │
              │      │                                │
              │      ▼                                │
              │  Contraste: ¿mi percepción = la del   │
              │  docente? → METACOGNICIÓN             │
              └──────────────────────────────────────┘
```

### Tipos de Retroalimentación

| Tipo | Frecuencia | Canal | Ejemplo |
|------|-----------|-------|---------|
| **Oral inmediata** | Cada sesión | En clase, durante o después de la actividad | "Majo, ¡eso sonó muy bien! ¿Notaste que mantuviste el pulso toda la canción?" |
| **Grupal** | Cada sesión | Cierre de sesión (5 min) | "Hoy el coro sonó más afinado que la semana pasada. Necesitamos trabajar las entradas del estribillo." |
| **Escrita formativa** | Cada corte | Nota en portafolio, mensaje, o Google Forms | "Santi: tu guitarra suena cada vez mejor. El siguiente paso es empezar a leer el cifrado mientras tocas, no solo de oído." |
| **Autorreflexión** | 3 por semestre | Instrumentos de autoevaluación | "¿Qué tan de acuerdo estoy con que he progresado?" |
| **Entre pares** | 2 por semestre | Instrumentos de coevaluación | "Un consejo constructivo para mi compañero..." |

## 12. Diferencias Evaluativas entre Semestre 1 y 2

| Aspecto | Semestre 1 | Semestre 2 |
|---------|-----------|-----------|
| **Diagnóstico** | Clasificación inicial A/B/C | Re-evaluación y posible reclasificación |
| **Tolerancia** | Mayor — es la primera experiencia | Menor — ya tienen un semestre de práctica |
| **Presentación** | Evaluada con flexibilidad (formativa-sumativa) | Evaluada con rigor completo (sumativa) |
| **Creatividad** | No se pide composición ni arreglo | Se espera al menos 1 aportación creativa (arreglo, composición, dirección) |
| **Autonomía** | Docente guía el proceso completamente | Se espera mayor autonomía (elección de repertorio, co-dirección, trabajo independiente vía sitio web con 16 HEI) |
| **Portafolio** | Formato más guiado | Formato más libre, mayor profundidad reflexiva esperada |
| **Coevaluación** | Anónima y más estructurada | Puede ser semi-abierta si el grupo lo permite |
| **Horas de Estudio Independiente** | 4 HEI — uso básico del sitio web | 16 HEI — uso autónomo significativo del sitio web y práctica personal |

## 13. Uso del Sitio Web en la Evaluación

El sitio web complementario se integra en la evaluación de la siguiente manera:

| Momento | Cómo se integra el sitio web | Instrumento afectado |
|---------|------------------------------|---------------------|
| **Diagnóstico** | El docente puede dirigir al sitio para que alumnos de Nivel C empiecen a nivelarse desde la semana 1 | No se evalúa — es recurso |
| **Proceso (Participación)** | Se registra si el alumno usa el sitio como parte de "progresión personal" | Rúbrica de Participación (criterio 5) |
| **Habilidades** | El alumno puede mostrar evidencia de ejercicios completados en el sitio | Rúbrica de Habilidades |
| **Portafolio** | Screenshots o notas del sitio como evidencia de práctica | Rúbrica de Portafolio (criterio 1: registro de práctica) |
| **Autoevaluación** | Pregunta explícita: "¿He usado el sitio web por mi cuenta?" | Instrumento de Autoevaluación (ítems 6 y 12) |
| **Sem 2 — HEI** | Las 16 horas de estudio independiente se documentan parcialmente con actividad en el sitio | Portafolio + Habilidades |

> ⚠️ **El uso del sitio web NUNCA es obligatorio para aprobar** — es un recurso de apoyo. Pero su uso consistente contribuye positivamente a las evidencias de proceso y progresión.
